Hosts this AInode asks when it searches

Every search goes to your model host, and to any host you add here. A search runs once after each engine start, as soon as this window is shown; when this view opens or refreshes; and when you search. Each host asked sees this computer’s IP address, and the words you search for. AInode fetches models only from its model host, not from the hosts you add.

A host name or an IP address, and its port. Up to 4 hosts: each one that does not answer makes every search wait a little longer. A host the engine cannot reach from here is simply not asked.

Read-only. AInode only downloads: it never funds, awards or pays, and has no wallet. Funding a bounty or a release takes a BTX node with a wallet; "How to fund this" on a card says what that takes. Lists and counts here are what this AInode's hosts answered, not a count of the whole network. An amount raised is shown only when the engine knows it from the chain. Unlike upstream's own app, AInode uses one host at a time and chats only with the models in its store; a model from a link is kept as files you can open.
